Informativa sulla privacy — garmin-connect

Ultimo aggiornamento: 15 novembre 2026

  • Chi la usa. L'applicazione è usata solo dal suo proprietario, sui propri dati.
  • Quali dati di Google. Con l'ambito drive.file l'applicazione accede solo ai file e alle cartelle che crea essa stessa nel Google Drive del proprietario. Non legge né modifica altri file.
  • Uso. I file servono solo a conservare e analizzare gli allenamenti del proprietario.
  • Condivisione. Nessun dato viene venduto, ceduto o condiviso con terzi.
  • Conservazione e cancellazione. I file restano nel Drive del proprietario, che può cancellarli in qualunque momento e revocare l'accesso dell'applicazione da myaccount.google.com/permissions.

L'uso delle informazioni ricevute dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di uso limitato (Limited Use).

English. This application is used only by its owner, on the owner's own data. With the drive.file scope it accesses only the files and folders it creates in the owner's Google Drive. No data is sold, transferred or shared with third parties. The owner can delete the files and revoke access at any time. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
